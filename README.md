## Scope

This repository's README is the source of the public index. yaal maintains only Awesome List repositories generated by yaal: a nested yaal git submodule, a yaal.config.yaml, and a yaal-built site (typically GitHub Pages). Product entries belong in those instance lists, not here. Do not add a repository merely because it is an awesome list. Third-party directories that do not use yaal to generate their site are out of scope. Retired or merged lists (Awesome-Vibe-Coding, Awesome-Personal-Agents, Awesome-Agent-Services) are not listed and should not be re-added.

## Artificial Intelligence

> Curated collection of AI-related awesome lists covering artificial intelligence tools, resources, and learning materials.

### Large Language Models

> Resources and tools specifically focused on large language models.

#### [Awesome-LLM-RL](https://github.com/0xWelt/Awesome-LLM-RL)

A curated list of open-source projects, tools, and learning resources about Reinforcement Learning with LLMs, featuring frameworks like OpenRLHF built on Ray, vLLM, ZeRO-3 and HuggingFace Transformers.

### AI Agents

> Curated collections of AI agent frameworks, tools, and platforms.

#### [Awesome-Agent-Ecosystem](https://github.com/0xWelt/Awesome-Agent-Ecosystem)
